# J

写代码的，主要在 Python 和 TypeScript 之间来回写，偶尔碰 C++。做的东西大多跟 LLM 有关：Agent、爬虫、数据分析、量化回测。自己干活缺什么就造什么，造完就放上来。

## 项目

- **A 股投研系统** — [stock-research-system](https://github.com/xiaomaozjj666/stock-research-system)：多专家分析、量化回测、模拟盘，一套下来挺全
- **数据分析工作台** — [data-analysis-agent](https://github.com/xiaomaozjj666/data-analysis-agent)：丢个数据集进去，自动清洗、统计、出报告
- **Issue 根因分析** — [issue-agent](https://github.com/xiaomaozjj666/issue-agent)：自动排查 GitHub Issue，输出带行号证据的修复建议，默认只读
- **隐身爬虫库** — [web-crawler](https://github.com/xiaomaozjj666/web-crawler)：TLS 指纹、自适应选择器、JS 逆向、验证码识别
- **中转 API 质检** — [relay-audit](https://github.com/xiaomaozjj666/relay-audit)：安全、身份、质量、性能一次跑完，出 HTML 报告
- **四语言入门练习** — [programming-exercises](https://github.com/xiaomaozjj666/programming-exercises)：hello world 到进制转换，code-practice 和 base-conversion 都并进来了

[base-conversion](https://github.com/xiaomaozjj666/base-conversion) 和 [code-practice](https://github.com/xiaomaozjj666/code-practice) 已归档，内容都在上面最后一条里。

还有 3 个私有仓库（微信 AI 机器人、Obsidian 笔记库、比赛用的服务机器人），基本自己用，就不放出来了。
